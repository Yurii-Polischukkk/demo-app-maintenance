# DemoApp

Навчальний консольний застосунок для відпрацювання супроводу програмного забезпечення в Git
(гілки `dev` → `release/*` → `master`, Pull Request, теги версій).

Програма запитує ім’я користувача та виводить привітання.

## Гілки

- `dev` — основна розробка (гілка за замовчуванням);
- `release/x.y` — підготовка релізу;
- `master` — лише готові перевірені версії, зміни тільки через Pull Request.

## Запуск

```
cd DemoApp
dotnet run
```
